# Пара 2. Линейная регрессия

Лекция на 90 минут: линейная модель и матрица плана, нормальные уравнения, геометрия остатка, коллинеарность, гауссов и лапласов шум, условия Гаусса–Маркова, абсолютные, относительные и квантильные метрики, затем train / validation / test как место, где эти веса можно судить.

## Открыть презентацию

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем в браузере:

```text
http://localhost:8000/materials/Пара2/
http://localhost:8000/materials/Пара2/методичка.html
```

PDF методички: `output/pdf/МЕТОДИЧКА_ПАРЫ_2.pdf`. Собрать заново:

```bash
tectonic -o output/pdf materials/Пара2/методичка.tex
mv output/pdf/методичка.pdf output/pdf/МЕТОДИЧКА_ПАРЫ_2.pdf
```

Стрелки или пробел — слайды. `F` — полный экран. `S` — заметки докладчика. `Esc` — обзор слайдов.

Оформление, Reveal.js и KaTeX берутся из пары 1, поэтому папку `materials/Пара1/vendor` удалять нельзя.

## Файлы

- `index.html` — студенческая презентация со скрытыми заметками;
- `методичка.tex` — студенческая методичка; PDF: `../../output/pdf/МЕТОДИЧКА_ПАРЫ_2.pdf`;
- `методичка.html` — короткая раздатка в браузере; полный конспект с определениями и выводом — в PDF;
- `figures/` — рисунки к слайдам и методичке;
- `styles.css` — дополнение к оформлению пары 1;
- `КОНСПЕКТ_ПАРЫ_2.tex` — конспект преподавателя с выводами;
- `МЕТОДИЧКА_ПРЕПОДАВАТЕЛЯ.tex` — разбор каждого слайда простым языком; PDF: `../../output/pdf/МЕТОДИЧКА_ПРЕПОДАВАТЕЛЯ.pdf`;
- `НА_ЗАВТРА.md` — короткая карта тех же слайдов;
- `ПОДГОТОВКА_ПРЕПОДАВАТЕЛЯ.md` — короткий список ловушек перед выходом.

Собранный PDF конспекта: `../../output/pdf/КОНСПЕКТ_ПАРЫ_2.pdf`.

## Опора

Оценка качества и запрет смешивать выборки — по учебнику Яндекса, без переноса текста: [1.3](https://contest.yandex.ru/tracks/ml/introduction/machine-learning), [3.1](https://contest.yandex.ru/tracks/ml/model-evaluation/introduction), [3.2](https://contest.yandex.ru/tracks/ml/model-evaluation/classification-and-regression-metrics), [3.3](https://contest.yandex.ru/tracks/ml/model-evaluation/cross-validation).

Устройство МНК — в том же контуре, что лекции по линейным моделям курса ВШЭ (Е. А. Соколов) и глава 3 ESL (Hastie, Tibshirani, Friedman): нормальные уравнения, проекция, различие loss и метрики. Текст слайдов эти источники не повторяет. Градиентный спуск, полиномиальные столбцы и регуляризация оставлены следующим неделям курса.

# Пара 1. Введение в машинное обучение

В папке лежит углублённая вводная лекция на 90 минут в формате Reveal.js и конспект преподавателя, подготовленный в LaTeX и собранный в PDF.

## Открыть презентацию

Запустите локальный сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000/materials/Пара1/
```

Переключение слайдов: стрелки или пробел. Полный экран: `F`. Режим докладчика со скрытыми заметками: `S`. Обзор всех слайдов: `Esc`.

Reveal.js 6.0.1 и плагин заметок включены локально в `vendor/reveal.js`. Формулы записаны в `index.html` на LaTeX (`\[...\]`) и отображаются локальной KaTeX 0.18.9 из `vendor/katex`, включая шрифты. Поэтому презентация работает без внешних скриптов. Шрифт Manrope загружается из Google Fonts; при отсутствии интернета используется Arial. Картинка roadmap берётся из `assets` репозитория.

## Файлы

- `index.html` — студенческая презентация со скрытыми заметками для докладчика;
- `styles.css` — оформление в цветах roadmap курса;
- `ПОДГОТОВКА_ПРЕПОДАВАТЕЛЯ.md` — сценарий, тайминг и акценты по каждому слайду;
- `КОНСПЕКТ_ЛЕКЦИИ.tex` — полный редактируемый конспект преподавателя; готовый PDF — в `../../output/pdf/КОНСПЕКТ_ЛЕКЦИИ.pdf`;
- `vendor/reveal.js` — закреплённая локальная копия Reveal.js с лицензией.
- `vendor/katex` — закреплённая локальная копия KaTeX с лицензией и шрифтами.

## Перед показом

Расскажите на первом слайде о себе и одном собственном ML-кейсе. Эти личные сведения намеренно не заполнены в презентации. Проверьте, что система оценивания всё ещё отмечена как «в разработке»; конкретные баллы в этой лекции не объявляются.

## Содержание

30 слайдов: коротко о цели курса → почему классическое ML важно для интервью → когда ML уместен → обучение с учителем и без → типы задач и семейства алгоритмов → сквозной пример квартиры → утечка и эмпирический риск → обобщение и честная проверка → baseline и метрика → полный маршрут решения.

Методический ориентир — [«Тренировки по ML 1.0» Яндекса](https://www.youtube.com/watch?v=k3UJOG-DKHE&list=PLXtiZNKIobF5wGW0ExSn47db1I8uYnfIC), особенно формальная постановка задачи и объяснение через конкретный пример. Лекционный материал адаптирован к отдельной вводной паре.
